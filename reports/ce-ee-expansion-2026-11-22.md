# 计算机工程与电子电气扩充

2026-11-22。用户要求技能树不再只是计算机科学与技术专业，而是把计算机科学（CS）、计算机工程（CE）和电子电气（EE）都尽量覆盖，并给游戏加上硬件方向的远征。本文记录选了哪些技能、依据是什么、前置关系怎么定，以及还不够好的地方。

## 1. 依据的标准

| 标准 | 用途 | 状态 |
|---|---|---|
| ACM/IEEE-CS/AAAI **CS2023** | 原有的 CS 主干判定 | 不变 |
| ACM/IEEE-CS **CE2016**（Computer Engineering Curricula 2016） | CE 的知识领域与核心学时；新的 CE 主干判定 | 现行版本。查过 ACM 课程推荐页与 IEEE-CS 课程卷页，没有更新的 CE 卷；之后的 CC2020 只给能力框架，不列 CE 课程 |
| 教育部《普通高等学校本科专业类教学质量国家标准》（2018，高等教育出版社） | 电子信息类（0807）、电气类（0806）的必修知识领域和核心课程示例；EE 主干判定与远征目标 | 官方只出纸质书。用高校托管的扫描件（无文字层），主代理逐页看图核对了 p.301、p.302、p.309、p.311、p.312 的原文 |
| NCEES **FE Electrical and Computer** 考试大纲（2020 年 7 月起执行） | 对照覆盖面，找缺口 | 17 个知识领域里，工程经济学原来不在树里，这次补上 |
| ABET 电子/计算机工程专业认证准则 | 只说明认证要求包含哪类数学和工程专题，不列课程 | 不作为技能来源 |

IEEE 没有正式的 EE 知识体系文件。英国 AHEP 只有通用学习结果，不分学科。

## 2. 新增的技能

两个新领域：**N 物理基础**、**E 电子信息与电气工程**。H 领域补了 9 个，I 领域补了工程经济学，共 35 个新技能，全树从 193 个增加到 228 个。

| 领域 | 技能 |
|---|---|
| N 物理基础 | 大学物理：力学与热学、大学物理：电磁学、振动波动与光学、量子力学基础、固体与半导体物理 |
| E.1 电磁场、射频与光电子 | 电磁场与电磁波、微波工程与天线、射频与高频电路、光电子与光纤通信、射频集成电路设计、电磁兼容与信号完整性、雷达原理、卫星导航与定位、激光原理与技术 |
| E.2 信号处理与通信 | 数字信号处理、统计信号处理、通信原理、无线与移动通信、自适应信号处理 |
| E.3 电力电子与电力系统 | 电力电子技术、电机与电力拖动、电力系统分析、高电压技术、电力系统继电保护、新能源发电与储能 |
| H 硬件（补充） | 模拟电子技术、电子测量与仪器、模拟集成电路设计、集成电路制造工艺、EDA 算法、SoC 设计与片上互连、MEMS 与微传感器、PLC 与工业自动化、过程控制 |
| I 信息系统（补充） | 工程经济学 |

分两批加。第一批 23 个，是国标核心课程示例、CE2016 核心领域和五所学校（MIT、Berkeley、Stanford、佐治亚理工、清华/电子科大/浙大）培养方案里的必修课。用户问“为什么比计算机专业的技能点少这么多”之后，又加了第二批 12 个：国标“专业知识”清单点名、或至少两所强校单独开课的专业方向课。

没有收的：光学设计、光电检测、信息光学这类光电信息专业的专门课（树里没有能挂靠的技能群）；数字图像处理、语音信号处理（已由 A.3.2、A.3.3 覆盖）；电子系统设计、通信概论这类综合课。

技能大小按一门课程单元判定，每个都有 2–3 门真实大学课程的范围和学时作依据（`granularity.json`）。自适应信号处理只够一个进阶模块（国科大两门课里各占 12–15 学时），标为“进阶模块”。

## 3. 前置关系

35 个新技能都按项目原有规则判定：**必须前置** = 至少一门真实大学课程把它列为先修，并且不会它就学不懂本技能入门层的内容；**推荐前置** = 只有部分课程要求，或只在深入层用到。每条必须前置都在 `data/research/nodes/<id>.json` 里有课程先修原文和网址，`check_prereqs.py` 全部通过。

先修证据由 pi 子代理检索，主代理逐条复核。复核中改掉的错误：

- MIT 的 “Calculus II (GIR)” 是 18.02 多元微积分，pi 映射成了一元积分 M.1.3；已按课程实际内容改映射。
- PLC（H.4.5）第一轮唯一写了先修的课，其先修课 IT 2608 其实是数控加工课，pi 却映射到了电路；重查后改用北京信息科技大学和 Rock Valley College 的 PLC 课（先修电路、模电、数电）。
- 激光原理（E.1.9）原候选必须前置量子力学，三门课都不要求，厦门大学课程问答明说没学过也听得懂，改为推荐。
- SoC（H.2.9）只有北京工业大学（微电子专业）要求先修集成电路设计，国科大的通用 SoC 课不要求，所以必须前置只取两门课都要求的数字电路。

有中外差异的地方按国内顺序取，避免成环：MIT 6.685 电机学要求先修电力系统，华北电力和 Berkeley 是先学电机再学电力系统；树里取后者。

**新的关联关系。** 另外核对了 16 个原有技能的课程是否要求新技能，结果只加推荐前置，没有加必须前置。原因都是只有部分课程要求：

| 原有技能 | 新的推荐前置 | 依据 |
|---|---|---|
| H.1.1 电路与模拟电子基础 | N.1.2 大学物理电磁学 | MIT 6.2000 要求；UCSD 只强烈建议，Berkeley 只要求数学 |
| H.2.5 半导体器件 | N.2.2 固体与半导体物理 | UCSD ECE 135B 要求；MIT、Berkeley 课内讲 |
| X.3.1 量子计算 | N.2.1 量子力学基础 | MIT 8.371 要求；计算机系的量子计算课多只要求线性代数 |
| H.4.2 机器人 | N.1.1 力学 | MIT 2.120 要求动力学 |
| H.3.3 传感器与接口、H.2.4 VLSI | H.1.4 模拟电子技术 | UCSD ECE 118、ECE 165 要求 |
| H.4.1 控制理论 | H.1.1 电路、E.2.2 统计信号处理 | MIT 6.7120 要求电路；卡尔曼滤波的推导 |
| C.3.3 无线网络 | E.2.3 通信原理 | 物理层 |
| A.3.2 视觉、A.3.3 语音 | E.2.1 数字信号处理 | 二维滤波、语音分帧 |

X.3.1 的简介原来写“外部前置为量子力学基础”，现在量子力学已经在树里，改为“量子力学基础见物理领域N.2.1”。

## 4. 主干和选修

原来只按 CS2023 判主干。树扩到三个专业以后，规则改为任一份标准算核心就是主干：CS2023（原规则）、CE2016（简介里至少一半的知识点在有核心学时的知识单元的核心学习成果里有原文）、国标（知识领域被列为该专业类每个学生都要覆盖的内容）。详情面板新增“CS 主干 / CE 主干 / EE 主干”标签。

`check_scope.py` 新增了 CE2016 解析：134 个知识单元、116 个有核心学时，与 CE2016 表 A-1 一致。每段 CE 原文片段都在所引单元的核心学习成果里找到，不认同一单元里的选修学习成果。国标是扫描件，脚本只能核对引用结构；条文本身由主代理看扫描页逐字核对，记在 `standards-cn.json`。

国标只采用写明“须涵盖”“包括”的硬性清单：电子信息类学科基础知识（电路与电子技术、计算机系统与应用、信号与系统、电磁场与波）和通识类里的大学物理（力学、热学、电磁学、光学、近代物理）。电气类工程基础和专业基础类课程的原文是“在下列核心知识内容中有所侧重、取舍”，各专业的专业基础知识是“至少 4 个”，都不当作每个学生必修。因此通信原理、电力电子、电机、电力系统都是选修，并在理由里写明。

结果（草稿构建）：主干从 122 个变为 132 个。原有技能里，H.2.5 半导体器件（CE2016 CE-CAE-5/6）和 H.4.3 物联网（CE-ESY-10/11）由选修变为 CE 主干。

## 5. 练习、导览图和学习路线

- **练习题**：每个新技能一道综合题，主代理出题，所有数值用 Python 算过，覆盖项与简介知识点逐条对应。
- **知识导览图**：35 张，标题与来源原文逐条核对（missing 0）。复核时撤掉了三类不合格来源：行业杂志站托管的教材目录（改用美国国会图书馆编目或出版社页）、网店页面上的目录、未经授权公开的整书 PDF（高电压技术的 Holtzhausen & Vosloo 草稿版，首页写明“All rights reserved”，托管它的图书馆没有授权证据）。
- **双语学习路线**：中英文各自覆盖每个必学知识点。复核时确立了一条新规则：**课程教学大纲、课程手册不是教学材料**，只能作证据或参考，不能计入覆盖。第一轮有几个技能把大纲当成中文主资源，返工后如实降低了中文覆盖，缺的知识点查过文字、视频、付费三个渠道后用英文补读。

截至存档时，35 个新技能里 29 个的双语路线已归档；中文覆盖较弱的是 SoC（1/8）、电子测量（3/8）、EDA 算法（4/8）、统计信号处理（4/8）、新能源（4/7），缺的部分按规则用英文补读。

## 6. 已知不足

- 几张导览图只有章一级（E.1.7 雷达、E.2.2 统计信号处理、E.3.2 电机、E.3.3 电力系统、H.2.6 模拟集成电路）：出版社页只给到章，课程页只有讲次标题。可以在下一轮“加深”时换来源。
- 导览图没找到对应章节、按说明留空的知识点：电力系统的“新能源并网概述”、电磁兼容的“高速信号的时序与眼图”、激光的“激光调制与偏转”、导航的“惯性导航与组合导航”（只有一小节）。
- 高电压技术的补充大纲托管在重庆大学的远程教育平台（重庆重大远兴科技发展有限公司），不是学校主站。
- 微波工程的开放教材在 NCSU 库对脚本启用了人机验证，目录用的是同一文件的 Wayback 存档核对；给读者的链接仍是 NCSU 官方地址。
- 许多中文课程的逐讲目录只能从 B 站转载录像的分集标题读到，按“官方版优先”规则，官方 MOOC 作主资源，转载录像只作章节依据并标明“第三方转载，授权未核”。
- 自动化类（0808）的国标条文没有逐字核对扫描件，因此自动化相关技能不以它判主干；游戏的“电气控制与自动化”远征按电气类示例三排出。
