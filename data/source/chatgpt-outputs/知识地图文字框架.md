# 计算机科学与数学知识地图（中文）

本图覆盖所给清单的全部显式科目，并扩充主干缺口。它是适合学习规划的知识地图，不宣称穷尽数学、计算机或所有行业的研究子领域。

## 阅读规则

- **归属编码**：如 `M.1.4.2` 是“数学 → 分析与微积分 → 多元微积分 → 梯度与雅可比矩阵”。点号层数仅表示包含层级；一级大类、二级分支、三级主题，必要时细到四级。
- **深度编码**：D1 核心基础；D2 工程实践；D3 专业深入；D4 高级理论与科研专题。D编码不决定所属领域，也不是难度排行榜；同一科目可跨多个深度。
- **包含**：父节点组织子内容。为了去重，每项选择一个主要归属；相交领域用关联边保留多个视角。标题为组织性分组时，不声称其中各学科存在唯一严格的数学集合包含关系。
- **前置**：`A → B` 表示本图建议的主要概念或学习前置，附有理由；不是所有路线的硬性先修，也不是全部依赖的穷尽图。基础可并行、交错推进。
- **关联**：`A ↔ B` 表示方法共享、范围交叠或跨领域应用，不表示两个主题相同。
- **可选应用方向**：X域包含原清单中的行业与前沿项目；通用学习路径中可按目标后置，不表示该领域简单或价值低。没有另设“第五层”。

## 四层学习深度与验收

| 编码 | 名称 | 典型验收 |
|---|---|---|
| D1 | 核心基础 | 解释基本概念，掌握表示与基础推理，完成小规模手算或程序。 |
| D2 | 工程实践 | 实现、使用与测试方法，在明确约束下完成可运行、可验证的任务。 |
| D3 | 专业深入 | 推导与分析机制，比较方法和适用假设，理解复杂性、稳定性或质量权衡。 |
| D4 | 高级理论与科研专题 | 阅读论文、严谨证明或复现实验，研究假设、边界、失效模式与开放问题。 |

例如线性代数在D1学空间与线性方程，在D2实现最小二乘，在D3解释分解与谱结构；D4的矩阵研究仍留在代数领域。教育科技即使按通用路径后置，也可在D4研究学习干预的因果效果。

## 易读总框架

### M　数学基础与方法

研究数量、结构、空间、变化与不确定性；为理论计算、工程建模和科学计算提供语言。

- **M.1 分析与微积分**：极限与连续；一元微分学；一元积分学；多元微积分；无穷级数；实分析；泛函分析；复分析；傅里叶分析与调和分析
- **M.2 微分方程与动力系统**：常微分方程；偏微分方程；动力系统与混沌；变分法与最优控制数学
- **M.3 线性结构、代数与数论**：线性代数；矩阵理论与矩阵分析；张量代数与多重线性代数；代数结构与抽象代数；数论；代数几何与表示论专题
- **M.4 几何与拓扑**：向量代数与解析几何；微分几何；拓扑学；计算几何与几何处理；拓扑数据分析与几何学习数学
- **M.5 离散数学与逻辑基础**：集合论；数理逻辑；证明方法与离散结构；组合数学；图论
- **M.6 概率、统计与信息**：概率论；数理统计；随机过程；时间序列与排队论；信息论与编码理论
- **M.7 优化与运筹**：优化建模与运筹基础；凸优化；非凸优化；随机优化；离散与组合优化；博弈论与决策理论
- **M.8 计算数学与数值分析**：误差、稳定性与数值线性代数；插值、逼近与数值积分；微分方程数值解与科学计算；蒙特卡洛方法；自动微分与计算图；符号计算与计算代数

### F　理论计算机科学

研究可计算性、算法效率、程序的形式意义与正确性。

- **F.1 数据结构与算法**：数据结构；算法分析与设计；图算法与字符串算法；随机、近似与在线算法；并行、外存与流算法；参数化、次线性与精细复杂度算法
- **F.2 自动机、计算与复杂性**：形式语言与自动机；可计算性理论；计算复杂性理论；计算逻辑与自动定理证明
- **F.3 程序语言理论与形式化方法**：计算范式与λ演算；类型系统与程序语义；程序验证与模型检查；证明助手与形式化数学

### P　程序设计与软件工程

从表达计算到构造、交付、维护可靠软件；语言、平台与工程过程分开组织。

- **P.1 程序设计基础与范式**：程序设计基础；面向对象程序设计；函数式、逻辑式与声明式编程；高级程序设计
- **P.2 程序语言与开发工具**：Java程序设计；C/C++与底层编程；Python与科学计算工具；版本控制、调试与构建工具
- **P.3 编译器与运行时**：编译原理；运行时、虚拟机与内存管理
- **P.4 软件工程与软件架构**：软件工程基础与开发方法；需求工程与领域建模；软件设计与面向对象分析设计；软件架构；软件测试、质量与可靠性；软件维护、演化与技术债
- **P.5 应用开发与软件交付**：互联网与Web开发；移动、桌面与跨平台开发；DevOps、持续交付与SRE；软件供应链与可复现构建

### C　计算机系统与网络

从指令执行、操作系统、网络通信到分布式与高性能计算。

- **C.1 计算机组成与体系结构**：计算机组成原理；计算机体系结构；ARM与其他指令集体系；GPU、加速器与异构系统
- **C.2 操作系统与系统软件**：操作系统；系统编程与并发同步；虚拟化、容器与资源管理；存储系统与文件系统
- **C.3 数据通信与计算机网络**：数据通信与信号基础；网络协议、路由与传输；无线、移动与物联网网络；网络管理、SDN与可编程网络
- **C.4 分布式系统与云计算**：分布式系统；云计算；分布式算法与一致性理论；消息、事件与流处理系统
- **C.5 并行计算与高性能计算**：共享/分布式内存并行编程；GPU计算与性能优化；高性能科学计算

### D　数据管理与数据科学

组织、保存、处理和解释数据；数据科学同时依赖数学、AI和可视化。

- **D.1 数据库系统与数据管理**：数据建模、关系模型与SQL；数据库内核与查询优化；分布式数据库与NoSQL；数据库管理与安全；数据治理、元数据与质量
- **D.2 数据工程与大数据**：ETL/ELT与数据管线；大数据管理与处理；搜索、信息检索与推荐基础设施
- **D.3 数据科学、统计分析与挖掘**：数据科学导论与工具箱；知识发现与数据挖掘；评估、实验与可复现分析
- **D.4 知识与信息工程**：知识表示、知识图谱与本体；知识推理与语义计算

### A　人工智能与机器学习

研究智能行为的表示、推理、学习、感知和决策；机器学习是AI的重要子领域。

- **A.1 人工智能基础与智能系统**：搜索、规划与约束求解；概率图模型与不确定推理
- **A.2 机器学习**：监督、无监督与半监督学习；学习理论与泛化；深度学习；强化学习；迁移、多任务与联邦学习
- **A.3 感知、语言与内容生成**：自然语言处理；图像处理与计算机视觉；语音与音频智能；推荐系统；生成式AI
- **A.4 AI工程、可靠性与科研**：机器学习工程与MLOps；可信AI、可解释性与公平性；AI安全与模型系统安全；多智能体、因果与神经符号专题

### S　网络空间安全

从威胁建模、密码学到系统/网络/应用防护、检测响应与安全研究；各安全课程按对象去重。

- **S.1 安全基础与密码学**：安全原理、威胁建模与风险；密码学；现代密码与隐私计算专题
- **S.2 系统、网络与平台安全**：计算机系统安全；网络安全；无线与移动安全；云安全与容器安全；硬件、嵌入式与物联网安全
- **S.3 软件、应用与数据安全**：应用、Web与API安全；安全软件开发与程序分析；数据安全、隐私工程与访问控制
- **S.4 安全测试、取证与响应**：渗透测试、道德黑客与反制；计算机取证与事件响应；逆向工程与恶意软件分析；安全运营、检测与攻防评估
- **S.5 安全理论与研究**：协议验证与信息流安全；系统安全研究与安全测量

### H　电子硬件、嵌入式与控制

从电路与逻辑到芯片、设备软件、感知控制与物理世界接口。

- **H.1 电子与数字逻辑基础**：电路与模拟电子基础；数字电路与数字逻辑；信号与系统、数字信号处理
- **H.2 硬件设计与集成电路**：FPGA与Verilog/HDL；EDA与硬件验证；PCB设计与板级工程；VLSI与芯片设计；半导体器件与微电子基础
- **H.3 嵌入式系统与设备接口**：单片机与微控制器；嵌入式系统、驱动与RTOS；传感器与接口；实时系统与安全关键系统
- **H.4 控制、机器人与物联网**：控制理论与状态估计；机器人建模、规划与控制；物联网；边缘计算

### V　图形、多媒体与人机交互

生成与呈现视觉/媒体内容，研究人与计算系统的交互；计算机视觉主要归AI。

- **V.1 计算机图形学与媒体计算**：计算机图形学；多媒体技术；渲染、仿真与可微图形专题
- **V.2 人机交互与用户体验**：交互基础与认知、人因；用户研究、交互设计与UX评估；可访问性与包容性设计；XR、空间交互与协作系统
- **V.3 数据可视化与可视分析**：数据可视化与交互设计；科学可视化与可视分析

### I　信息系统、组织与专业实践

研究技术与组织、业务、人的协作，以及伦理、项目治理和科研实践。

- **I.1 信息系统与业务**：信息系统基础；信息系统战略与管理；业务流程管理；信息技术项目管理
- **I.2 专业伦理、治理与科研方法**：计算伦理、社会影响与专业责任；技术写作、协作与文献阅读；研究设计、可复现性与学术规范

### X　交叉应用与前沿专题

按目标组合主干领域；多数为应用方向或科研专题，不是所有人都应先学的公共基础。

- **X.1 智能设备与自主系统**：嵌入式AI；边缘AI；自动驾驶与自主系统
- **X.2 科学与行业计算**：生物信息与计算生物学；金融科技与计算金融；教育科技与学习科学计算；医疗健康信息学；地理空间、气候与数字人文计算
- **X.3 新型计算与可信协作**：量子计算与量子信息；区块链与分布式账本；科学机器学习与可微仿真

## 完整分层目录

每行的D标记表示此图展开的学习阶段；父节点的深度表示其分支范围，非要求每个子项均学到同一深度。

### M　数学基础与方法

- **M.1 分析与微积分**〔D1 / D2 / D3 / D4〕：从极限与微积分到实分析、复分析与泛函分析。多元微积分包含多元微分和多重、曲线、曲面积分。
  - **M.1.1 极限与连续**〔D1 / D3〕：数列与函数极限、无穷小、连续性、紧致区间上的基本性质。
  - **M.1.2 一元微分学**〔D1 / D2 / D3〕：导数、微分、微分中值定理、泰勒公式与局部近似。
  - **M.1.3 一元积分学**〔D1 / D2 / D3〕：不定积分、定积分、微积分基本定理与反常积分。
  - **M.1.4 多元微积分**〔D1 / D2 / D3〕：多元函数的微分与积分总称；子项保留独立定位，避免与多元微分学混为一谈。
    - **M.1.4.1 多元微分学**〔D1 / D2 / D3〕：偏导数、全微分、方向导数、隐函数与逆函数定理。
    - **M.1.4.2 梯度与雅可比矩阵**〔D1 / D2 / D3〕：标量场梯度、向量映射导数、链式法则与坐标变换；属于多元微分工具。
    - **M.1.4.3 海森矩阵**〔D1 / D2 / D3〕：二阶偏导矩阵、二阶近似与极值判别；连接二阶优化。
    - **M.1.4.4 重积分**〔D1 / D2 / D3〕：二重、三重积分，区域分割、换元与雅可比行列式。
    - **M.1.4.5 曲线曲面积分与向量分析**〔D1 / D2 / D3〕：曲线与曲面积分、梯度/散度/旋度、Green/Gauss/Stokes定理。（合并名/别名：曲线曲面积分）
  - **M.1.5 无穷级数**〔D1 / D3〕：数项级数、函数项级数、幂级数、一致收敛与逐项运算。
  - **M.1.6 实分析**〔D3 / D4〕：实数完备性、函数序列、收敛交换与积分理论；为现代分析提供严谨基础。
    - **M.1.6.1 测度论与Lebesgue积分**〔D3 / D4〕：σ代数、测度、可测函数、收敛定理、乘积测度。（合并名/别名：测度论）
  - **M.1.7 泛函分析**〔D3 / D4〕：赋范空间、Banach/Hilbert空间、线性算子、对偶与谱理论。
  - **M.1.8 复分析**〔D3 / D4〕：解析函数、Cauchy理论、留数与保角映射。
  - **M.1.9 傅里叶分析与调和分析**〔D2 / D3 / D4〕：傅里叶级数/变换、小波、频域表示、函数空间与调和分析专题。
- **M.2 微分方程与动力系统**〔D2 / D3 / D4〕：连续时间模型、初边值问题、稳定性与系统演化。
  - **M.2.1 常微分方程**〔D2 / D3 / D4〕：一阶与高阶方程、线性方程组、存在唯一性、稳定性与数值求解。
  - **M.2.2 偏微分方程**〔D2 / D3 / D4〕：椭圆/抛物/双曲型方程、边界条件、弱解与适定性。
  - **M.2.3 动力系统与混沌**〔D3 / D4〕：相空间、平衡点、分岔、吸引子与混沌。
  - **M.2.4 变分法与最优控制数学**〔D3 / D4〕：泛函极值、Euler–Lagrange方程、变分原理与最优性条件。
- **M.3 线性结构、代数与数论**〔D1 / D2 / D3 / D4〕：线性与多重线性结构、抽象代数和整数结构；矩阵研究与线性代数高度交叠。
  - **M.3.1 线性代数**〔D1 / D2 / D3〕：向量空间、线性映射、线性方程组、矩阵、特征值、内积与正交分解。（合并名/别名：线代）
  - **M.3.2 矩阵理论与矩阵分析**〔D2 / D3 / D4〕：矩阵范数、谱与奇异值分解、正定性、扰动、矩阵函数与不等式；合并两门高度重叠课程名称。（合并名/别名：矩阵论、矩阵分析）
  - **M.3.3 张量代数与多重线性代数**〔D2 / D3 / D4〕：张量积、缩并、坐标变换与张量分解；AI中的多维数组不等同于全部张量理论。（合并名/别名：张量代数）
  - **M.3.4 代数结构与抽象代数**〔D1 / D3 / D4〕：群、环、域、同态、商结构与有限域；高阶可进入表示论。（合并名/别名：代数结构）
  - **M.3.5 数论**〔D1 / D3 / D4〕：整除与同余、素数、数论算法、代数数论与解析数论专题。
  - **M.3.6 代数几何与表示论专题**〔D4〕：多项式理想、代数簇、群表示与结构方法；按研究目标选学。
- **M.4 几何与拓扑**〔D1 / D2 / D3 / D4〕：欧氏空间、曲率与流形、连续变形与拓扑不变量。
  - **M.4.1 向量代数与解析几何**〔D1 / D2 / D3〕：坐标、向量运算、直线/平面、二次曲线/曲面；与线性代数共享向量工具。
  - **M.4.2 微分几何**〔D3 / D4〕：曲线曲面、流形、切空间、度量、联络与曲率。
  - **M.4.3 拓扑学**〔D3 / D4〕：拓扑空间、连续性、紧致性、连通性、基本群与同调初步。
  - **M.4.4 计算几何与几何处理**〔D2 / D3 / D4〕：凸包、空间划分、网格、曲面处理与几何算法。
  - **M.4.5 拓扑数据分析与几何学习数学**〔D3 / D4〕：持续同调、流形方法、几何结构与数据表征；与AI共享应用。
- **M.5 离散数学与逻辑基础**〔D1 / D2 / D3 / D4〕：以离散结构为教学主线组织集合、逻辑、组合与图；这些分支各自也有独立理论。
  - **M.5.1 集合论**〔D1 / D3 / D4〕：集合运算、关系、映射、基数、序数与公理集合论。
  - **M.5.2 数理逻辑**〔D1 / D3 / D4〕：命题与谓词逻辑、推理、形式系统、模型论与证明论基础。

## 关键跨领域辨析

- 多元微积分包含多元微分、重积分和曲线曲面积分；梯度、Jacobian、Hessian是其中工具，不与整门微积分并列计为独立基础学科。
- 矩阵论与矩阵分析合为一个交叠课程入口；基础矩阵内容仍从属于线性代数，高阶矩阵专题在该入口展开。
- 计算数学覆盖数值分析，并包含随机与符号计算；本图合并导航入口但没有把两者定义为完全同义。
- 数理统计包含贝叶斯统计；随机过程包含Markov链；Monte Carlo是跨概率、计算和统计的计算方法，统一归M.8.4。
- AI包含机器学习，机器学习包含深度学习；强化学习也可采用非深度方法。NLP、视觉、语音、推荐是问题领域，和深度学习交叉而不全被其包含。
- 软件工程原理、实践与原则、开发方法学合并主入口；需求、设计、架构、测试和运维分别展开。架构与设计有交界，不是按难度拆开的学科。
- 数据库系统是数据管理领域的核心；数据库管理与安全是其中运营主题，与安全域的数据安全相交。数据科学不等于AI，也包括统计、管线、可视化和科学评估。
- 系统安全与计算机系统安全合并；网络空间安全是上位入口，网络安全、系统安全、应用安全等是不同对象下的分支。
- 计算机组成关注实现部件，体系结构关注接口与权衡；ARM是具体ISA体系。单片机是嵌入式平台之一，FPGA、EDA、PCB与VLSI不是彼此同义的课程。
- 嵌入式AI强调设备约束，边缘AI强调计算位置；二者相交。物联网强调设备互联，边缘计算强调部署策略。
- 图形学生成图像，计算机视觉解释图像；二者通过几何、渲染和逆问题连接。HCI研究人与系统，数据可视化研究数据的视觉表达与探索。

## 使用HTML

1. 双击 `计算机科学与数学知识地图.html`，无需联网或安装依赖。
2. 主视图是一张完整知识星图，所有259个节点同时保留在同一坐标空间；领域导航只移动视角，不切换局部地图。空间距离用于排布，不代表学习难度或精确学术相似度。
3. 拖动平移，滚轮或双指缩放，双击放大；左下小地图可点击或拖动定位。“全图”返回全局视野。缩小时显示星区，放大逐渐显示主题名称；鼠标悬停可查看全名。
4. 每次点击星点，右侧像科技树一样列出建议前置、包含的子分支、后续方向与交叉应用；点击建议会飞往对应节点并继续给出下一步。整张星图保留。
5. 选择D1–D4目标后，可以标记“我已掌握”。已记录分支会让位于未记录分支的推荐；前置尚未记录时给出提示，但不强制锁定主题。点击查看不等于完成学习。
6. 掌握记录按“主题×深度”分别保存，不自动完成父子项或其他深度。数据保存在当前浏览器，可导出备份并导入合并；更换浏览器或文件位置可能需要重新导入。
7. 搜索名称、别名或归属编码；D深度筛选仅改变高亮，其他主题不会从星图消失。关系图层开关控制包含、前置和交叉连线；勾选增强连线可提高全图关系的亮度。
8. “文字框架”提供可展开树；“原清单核对”和“图例与说明”可直接阅读。支持键盘操作、下载完整数据、文字框架、完整星图SVG与打印目录。
9. “跨学科桥梁”可一键高亮线代×概率统计×AI、系统×安全、控制×强化学习、教育科技×统计交互、图形学×视觉等真实关系。每组保留具体主题、方向、关系类型和解释，不把上位学科粗略当成一门先修课。
10. 全景中的星区桥梁由具体跨域关系汇总，并显示数量；选中一个大分支时，也会列出其子项通向其他领域的联系。线代与统计即使同属数学星区，它们之间的具体连线仍保留。
