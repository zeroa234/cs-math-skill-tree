# HCI / UX 验收记录（2026-10-31）

对象：`src/web/index.html`，包括领域总览、技能地图和详情面板。

方法有四种：
1. 自动化无障碍审计，标准是 WCAG 2.2 AA；
2. 键盘操作走查；
3. 启发式评估，按 Nielsen 十原则和 Shneiderman 的“先总览、再缩放过滤、细节按需”；
4. 任务走查。

这里没有做真人可用性测试，也没有用真实屏幕阅读器（NVDA / VoiceOver）试过，见文末“局限”。

复现命令：

| 命令 | 内容 |
|---|---|
| `node tests/a11y.mjs [report.json]` | axe-core 审计 + 键盘走查 |
| `node tests/screenshot.mjs` | 15 个界面场景截图，同时做深链回归检查 |
| `node tests/screenshot-panel.mjs <id>` | 单个技能详情面板的截图 |

本次结果存在 `docs/a11y-report.json`。

## 1. 自动化审计（axe-core 4.11.4）

规则集：wcag2a、wcag2aa、wcag21a、wcag21aa、wcag22aa、best-practice。

一共测了 12 个界面状态：
- 总览：浅色、深色；
- 地图 + 详情面板：浅色、深色；
- 地图（没选中技能）；
- 选中一条路线；
- 搜索下拉展开；
- 帮助对话框；
- 手机 390 宽的总览、手机地图 + 底部面板；
- 320 宽重排；
- 1366×768 笔记本。

| 项目 | 结果 |
|---|---|

## 2. 键盘走查（tests/a11y.mjs 自动执行，9 项全部通过）

- 第一次按 Tab 就到“跳到主要内容”；按回车，焦点进入第一个领域块。
- 每一个可聚焦的元素都有可见的焦点框（脚本逐个检查）。
- 在领域块上按回车，进入它的地图；按 Tab 能走到“现在能学”的卡片；按回车打开详情；按 L 点亮。
- 按 Esc 关闭详情，再按一次 Esc 回到总览；浏览器的后退键也能回到上一个视图。
- 用 Tab 聚焦到屏幕外的卡片时，地图不会被浏览器滚动错位。这个 bug 是在验收中发现并修复的。

## 3. 启发式评估

### Nielsen 十原则

| 原则 | 现状（证据） |
|---|---|
| 1 系统状态可见 | 顶栏显示“已点亮 / 总数 · 现在能学几个”，带进度条。总览每个领域块有进度、状态标记（可以开始 / 未解锁 / 已完成），以及按真实技能布局缩小的小地图。点亮后弹提示，列出这次解锁了哪些技能。选路线后，地图卡片和左栏都编上序号。 |
| 2 贴近真实世界 | 用“点亮 / 解锁 / 必须前置 / 推荐前置 / 第 N 步”这类技能树说法。中英双语名称，方便在国外上课对照。D1–D4 在帮助和标签提示里有解释。 |
| 3 用户控制与自由 | 点亮、取消、清空、导入都能撤销（提示里有“撤销”按钮）。Esc、浏览器后退和顶栏的“总览 / 技能地图”都能返回。每个视图都有自己的链接，可以收藏。 |
| 4 一致性与标准 | “已点亮 / 能学 / 未解锁”在小地图、卡片、左栏和详情面板里用同一套颜色和图标。实线 = 必须前置，虚线 = 推荐前置，各处一致。两个视图的操作也一致：滚轮缩放、拖动平移、右下角 +/−、按 0 或“适应屏幕”看全图（2026-11-01 补：总览原先用滚动条滑动，和地图不一致，用户指出后统一）。用的都是原生 button、select、dialog。 |
| 5 防错 | 前置没齐时“点亮”按钮不可用。取消一个已点亮技能时，如果会让后续技能失去前置，先要求确认。“清空进度”要点两次。导入的文件会先校验。 |
| 6 识别而非回忆 | 总览块上直接写“下一步：某技能”或“先学：某些领域”。详情面板列出每条前置的状态和理由。两个视图都有图例。 |
| 7 灵活高效 | 搜索（按 / 聚焦）、快捷键（L、Esc、0、+、−）、路线、“设为目标”、“我都会：连同前置一起点亮”、链接直达。 |
| 8 美观与简约 | 地图默认只画领域内部的连线，跨领域的前置用卡片左上角的彩点表示，选中技能后才画出整条链。总览默认只显示条数 ≥ 3 的主干连线，悬停时才显示全部并标出条数。 |
| 9 帮助识别和恢复错误 | 点锁住的技能，会提示“先点亮它的必须前置”，详情面板列出缺哪几个。导入失败有明确提示。 |
| 10 帮助与文档 | 首次打开显示“怎么用”，右上角 ? 打开帮助对话框，左栏有图例。 |

### Shneiderman 信息可视化原则

- **先总览**：首页是 13 个领域的总图。列由 ELK 按领域间依赖的最长链排出，第 1 列就是可以直接开始的领域。
- **缩放与过滤**：点一个领域进入它的地图并自动定位；支持路线 / 目标过滤、搜索、折叠领域。
- **细节按需**：点技能打开详情，包括前置理由、课程先修原文、学习资源和练习题。

## 5. 响应式与偏好设置

检查过的尺寸和设置：
- 1920×1080：总览按 0.97 倍完整显示；
- 1600×960；
- 1366×768：总览先缩到能看全图（实测 0.59 倍），再用滚轮放大；进入地图默认不低于 0.8 倍，多出来的部分平移查看；
- 390 宽手机：总览改成单列列表，详情变成底部面板；
- 320 宽：能正常重排；
- 浅色和深色模式都适配；
- 开启“减少动态效果”时，过渡动画和闪烁全部关闭。

## 6. 局限（如实说明）

- **没有真人测试**：结论来自自动审计、启发式评估和任务走查，没有找学生做出声思维或计时测试。
- **没用真实屏幕阅读器试**：只验证了可访问性树和 axe 规则。地图是空间画布，连线关系靠详情面板的列表传达，读屏用户应该从列表进入，而不是“看图”。
- **小屏笔记本要多操作一下**：1366×768 下，总览为了看全图缩到 0.59 倍（实测），领域名约 9px，要用滚轮放大才看得清。在地图里按“适应屏幕”会把全部 7 步缩进屏幕，这时卡片文字会小于 11px；这是用户主动选的，默认进入地图不会缩到这么小。
- **小地图颜色只是辅助**：“已点亮”（金）和“未解锁”（浅灰）的亮度差不大，色弱用户可能分不清。但每个领域块都用文字写了进度和状态，不只靠颜色。
- **触屏没在真机上试过**：Panzoom 支持双指缩放，但没有在真手机或平板上验证。
