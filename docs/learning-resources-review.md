优先保留大学课程、作者开放教材及项目官方教程。中文讲义、中文授课但英文课件、短篇中文导读分别注明；短篇导读、单项工具和仅覆盖部分分支的资料不标成完整课程。未登录验证付费/注册课程的全部视频与作业，也未承诺任何地区和网络都可访问。

## 网络复核结果

最终共有 291 个独立学习网址：普通 HTTP GET 中 290 个返回 200；Hello 算法返回 429，但在正常 Edge 浏览器中返回 200 且正文可读，因此保留，并记录自动请求限流。

另对 4 个依赖 JavaScript 的页面（南瓜书、动手学 ROS 2、IoT for Beginners、北大编译实践）用浏览器确认正文可读；3 个 PDF 用标题、目录或引言核实主题。张量教材的目录包含模的张量积、张量代数、对称代数与外代数。

机器可读记录在 `docs/learning-resources-link-check.json`，保留每次实际检查时间、HTTP 状态、跳转目标和浏览器/PDF 复核方式。链接检查属于当日快照，不保证未来或所有地区可访问。
